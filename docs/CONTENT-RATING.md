# Content rating (IARC) — jawaban untuk Play Console

Play Console memakai kuesioner **IARC** (International Age Rating Coalition) untuk
menghasilkan rating PEGI / ESRB / USK / CERO / dsb. Semua jawaban di bawah ini
sesuai isi game saat ini: game arkade menembak/melempar pisau ke roda putar dan
kepala bos **kartun**, tanpa darah, tanpa teks kasar, tanpa interaksi sosial,
tanpa pembelian uang nyata.

> Rating akhir tetap ditentukan IARC setelah kuesioner dikirim. Estimasi untuk
> jawaban di bawah: **PEGI 7 / ESRB Everyone 10+ / USK 6 / CERO A–B**.

---

## 1. Violence (kekerasan)

| Pertanyaan IARC | Jawaban | Catatan |
|---|---|---|
| Kekerasan terhadap manusia/hewan secara **realistis** | **Tidak** | Semua target adalah roda putar, kristal, dan kepala karakter kartun. |
| Kekerasan **fantasi/kartun** | **Ya — ringan (mild)** | Pisau/peluru mainan mengenai roda dan kepala bos kartun; tidak ada darah. |
| Darah, luka terbuka, mutilasi | **Tidak** | Tidak ada sama sekali. |
| Kekerasan seksual | **Tidak** | — |
| Kekerasan kepada karakter yang tidak bisa membalas | **Tidak** | Target adalah objek/roda, bukan karakter tak berdaya. |

## 2. Fear (unsur menakutkan)

| Pertanyaan | Jawaban | Catatan |
|---|---|---|
| Adegan/karakter yang bisa menakutkan anak kecil | **Ya — ringan** | Wajah bos kartun (pirate, jester, dll.) dengan ekspresi marah, tema gelap, dan efek suara mendadak. Tidak ada jumpscare realistis atau gore. |

## 3. Sexuality, language, substances

| Kategori | Jawaban |
|---|---|
| Konten seksual / ketelanjangan / pakaian provokatif | **Tidak** |
| Bahasa kasar / umpatan | **Tidak** — teks UI hanya pujian ("MANTAP!", "KEREN!", "GACOR!"). |
| Narkoba, alkohol, rokok | **Tidak** |

## 4. Gambling (perjudian)

| Pertanyaan | Jawaban | Catatan |
|---|---|---|
| Perjudian nyata (uang asli) | **Tidak** | Tidak ada taruhan, tidak ada pembelian uang nyata. |
| Simulasi perjudian (kasino, slot, kartu) | **Tidak** | Tidak ada mekanik kasino. |
| **Item acak / loot box** | **Ya — tetapi gratis** | Peti hadiah memberi senjata acak dari daftar tetap, dibeli/didapat dengan koin yang **hanya** diperoleh dari bermain. Tidak bisa dibeli dengan uang nyata, sehingga tidak ada kewajiban mengumumkan odds di store listing. Tetap jawab jujur bila Play menanyakan "randomized virtual items". |

## 5. Miscellaneous (interaksi & data)

| Pertanyaan | Jawaban |
|---|---|
| Pengguna bisa berinteraksi/berkomunikasi dengan pengguna lain | **Tidak** (tanpa chat, tanpa teman, tanpa leaderboard online) |
| Membagikan lokasi pengguna | **Tidak** |
| Membagikan info pribadi ke pihak ketiga | **Tidak** |
| Konten buatan pengguna (UGC) | **Tidak** |
| Pembelian digital (uang nyata) | **Tidak** |
| Akses internet tanpa batas / browser di dalam app | **Tidak** — tidak ada tautan keluar; satu-satunya tautan adalah `mailto:` untuk kontak privasi |
| Iklan | **Tidak** |
| Fitur kamera/mikrofon/lokasi | **Tidak** |

## 6. Target audience & konten

| Pertanyaan Play Console | Rekomendasi jawaban |
|---|---|
| Target age group | **13+** — paling sederhana (tidak memicu kebijakan Families). Kalau mau semua umur, siapkan review kebijakan *Designed for Families* tambahan. |
| Apakah aplikasi "primarily child-directed" | **Tidak** (kalau target 13+) |
| Iklan yang ditargetkan ke anak | **Tidak ada iklan sama sekali** |

Kalau target audiens diubah ke kelompok di bawah 13, Play akan meminta deklarasi
*Designed for Families*: pastikan tetap tanpa iklan, tanpa tautan keluar, dan
tanpa pengumpulan data — kondisi itu sudah terpenuhi saat ini.

## 7. Langkah di Play Console

1. App content → **Content rating** → mulai kuesioner IARC.
2. Masukkan email untuk menerima sertifikat rating.
3. Pilih kategori aplikasi: **Game**.
4. Jawab sesuai tabel di atas.
5. Kirim → rating muncul (PEGI/ESRB/USK/CERO) → tekan **Apply**.
6. Cocokkan dengan `docs/DATA-SAFETY.md` (jawaban "loot box" dan "iklan" harus
   konsisten di kedua tempat).
