# Fonts for the store artwork

Three text faces used by `tools/make-store-assets.ts` to lay out the icon,
feature graphic and screenshots. They are the same fonts the game ships
(`@fontsource/bungee`, `@fontsource/russo-one`, `@fontsource/fredoka`), converted
from WOFF2 to TTF so the offline renderer (`@napi-rs/canvas`) can load them.
